# Cinematic Contact Sheet

## Idea

The landing becomes an editorial contact sheet of three working proofs rather than one shared title transformed repeatedly by Tradimation.

```text
Yein Sung + proof index
→ rougher-stuff
→ trandimation
→ svgr2
→ Writing
```

The cinematic quality comes from complete full-viewport compositions, authored cuts, holds, and changes in visual density. Tradimation owns one chapter and one real movement. It is no longer the transition language of the whole page.

## Why the contact sheet exists

The first frame needs more evidence without adding decorative filler. Its lower field is therefore a functional project index. Each index item:

- links to a real chapter;
- contains a reduced final-state specimen from that chapter;
- establishes the chapter number used later;
- remains useful without motion.

The index is not a collage. It is the table of contents for the page and a preview of the exact three forms the viewer will encounter.

## Energy map

```text
Hero             composed, dense, completely static
rougher-stuff     expressive drawing, warm paper field
trandimation      one concentrated physical movement
svgr2             precise source-to-result switch
Writing           quiet document flow
```

## Frame 0 — Hero contact sheet

### What it shows

Yein Sung makes tools that mark, move, and transform interface material.

### Final frame

- `Yein Sung` is the largest object in the upper field.
- The existing two-line introduction supports it.
- Three linked proof cells form the lower contact sheet.
- Each cell contains a project name, chapter number, and exact miniature specimen.

### Elements and roles

- Identity title: establishes authorship.
- Intro sentence: states the scope of work.
- rougher-stuff cell: previews real notation output.
- trandimation cell: previews origin, destination, and the same HTML specimen.
- svgr2 cell: previews the exact triangle fixture and component representation.
- Cell borders: separate three interaction targets; they are not decorative frames.

### Motion

None. Generated rough notation mounts directly in its completed state. The first screenshot is the intended result.

## Frame 1 — rougher-stuff

### What it shows

Precise text receives actual expressive notation primitives.

### Final frame

Three large words form a disciplined typographic field with underline, circle, and bracket output generated by `@rougher-stuff/rough-notation`.

### Motion

The annotation group draws once in reading order. Leaving completes the group. Re-entry restores the completed marks immediately.

## Frame 2 — trandimation

### What it shows

One existing HTML element changes location while remaining one connected visual object.

### Final frame

The `same element` specimen rests on its computed destination registration. A source registration and one baseline explain where it came from without a decorative grid.

### Motion

The actual connected-texture `smear` runs once. No title, counter, background, or supporting label receives a Tradimation effect.

## Frame 3 — svgr2

### What it shows

The same SVG remains visually unchanged while its representation becomes a component.

### Final frame

The exact triangle fixture remains fixed above `<Icon />`; the qualified `29.99× JSX · tiny fixture` evidence remains secondary.

### Motion

Only `<svg> → <Icon />` uses `compress-swap`. The fixture, project title, and benchmark do not move.

## Frame 4 — Writing

### What it shows

Work ends and ordinary reading begins.

### Final frame

A warm document section contains the Writing title and recent posts. It does not reuse the contact-sheet cells or project-stage framing.

### Motion

None beyond link feedback.

## Page composition

- Every major frame occupies its own section and background rather than one shared sticky stage.
- Each project section uses a sticky inner composition only to create a hold; native scrolling remains untouched.
- Chapter identity uses real text and sequence numbers, not connecting arrows.
- Project cuts may change background and framing immediately because no shared object crosses those boundaries.
- Mobile keeps the same order: identity, intro, linked index, then one proof per section.

## Interaction contract

- Hero cells are normal anchor links to project sections.
- Proof effects start when the proof section owns the viewport center.
- A running effect is destroyed and settled when its section leaves.
- Effects never replay during the same visit.
- Fast anchor or scroll traversal never waits for an intermediate scene.
- Reduced motion mounts every proof in its completed state.

## Acceptance gate

- Removing the hero contact sheet would remove navigation and project preview, not merely decoration.
- The hero is a complete screenshot before JavaScript runs.
- Every contact-sheet cell maps to one later frame with the same form.
- rougher-stuff supplies most of the page's expressive texture.
- Tradimation appears only where an element actually moves.
- svgr2 keeps its fixture unchanged during the representation switch.
- No project boundary invents continuity between unrelated artifacts.
- Writing is quieter than all three project frames.
